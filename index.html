        Backup dos dados

        Os dados ficam no IndexedDB deste aparelho (sem o limite de 5 MB do V3). Baixe um backup com frequência — ele é o que protege contra perda do aparelho ou limpeza do navegador.

        Cópias automáticas

        Uma por dia de uso e antes de restaurar ou apagar. Ficam só neste aparelho (as 7 mais recentes).

          Aplicativo

          Instale o UniHub na tela inicial do Android ou do Windows para abrir como app e usar sem internet.

          Dados de demonstração
